# MusicXML score files

The 200 `.mxl` files in this folder are GuitarLoot arrangements, downloaded from
<https://guitarloot.org.uk/> and used under GuitarLoot's permission statement:

> You may freely use or adapt this arrangement provided you acknowledge me as its source.

The site acknowledges GuitarLoot on the score library page and links each score
back to <https://guitarloot.org.uk/>.

These files are MusicXML (compressed `.mxl`), not PDFs. They are rendered in the
browser with [OpenSheetMusicDisplay](https://github.com/opensheetmusicdisplay/opensheetmusicdisplay).

If you reuse these files elsewhere, keep the GuitarLoot attribution and check the
licence/rights for any public performance, recording, or commercial use.
